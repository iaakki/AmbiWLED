Controls

The same settings as Home Assistant's Controls card, in one place. Full explanations for each are in the panels below.

Mode

Ambilight streaming and a controller preset are both just something the strip is doing — AmbiWled only decides which. In Preset mode it stops streaming and tells the controller which stored preset to run, including an audio-reactive one if you have one set up. Turning this Off stops sending entirely; after the controller's realtime timeout the ceiling falls back to whatever it was already showing.

If your WLED controller is also added to Home Assistant directly, prefer its own preset picker — it has real names, this one is a bare slot number. This picker exists for setups where AmbiWled is the only integration point.

Auto-dim by the sun

Final output (this brightness × auto-dim) Auto-dim alone

Brightness sits at Night level all night, then follows a dome peaking at Day level at solar noon — brightest at midday, dimmest at dawn and dusk, meeting Night level exactly at sunrise and sunset with no jump. Curve shape 1 is a plain parabola; above 1 narrows the midday peak, below 1 broadens it toward a plateau. Times are computed locally from the coordinates — no external service, so it keeps working with the internet down. Above the Arctic circle it holds the day or night level through polar day and polar night.

Edges are packed head-to-tail in list order, so gaps and overlaps cannot happen — set each run’s Count and the starts follow. Use ↑ ↓ to match the order the strip physically runs. Identify lights that run for 10 s and works on what you are editing right now, even before it validates.

Front → back is one mirrored segment whose offset is set to the middle of the front run, so a single effect starts at the front centre and curls down both sides to meet at the rear — in phase, with no restart at the corners. One per edge gives each run its own effect instead. Both are derived from your edge layout, so the pixel arithmetic is done for you. Segments only affect WLED’s own effects — the realtime stream writes the whole strip and ignores them. Deriving them from the edges means one definition of the geometry rather than two. Keep WLED’s realtime segment set to “entire strip” (liveseg = -1) and its realtime LED offset at 0, or the stream will be confined.
